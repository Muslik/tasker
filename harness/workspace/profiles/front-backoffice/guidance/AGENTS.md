# Руководство для AI-агентов

Основное руководство проекта находится в `./.ai/index.md`. Прежде чем начать,
прочитай оттуда только документы, относящиеся к текущей задаче.

## Команды проверки проекта

- `pnpm run agent:typecheck` — быстрая инкрементальная проверка TypeScript.

`agent:eslint-for-changed` не является validation-командой Tasker: текущий script
запускает ESLint с `--fix` и может изменять файлы.

Tasker уже выбрал workflow, принял план, подготовил ветку и рабочий worktree.
Выполняй только текущий шаг: не создавай другой worktree, не запускай второй
planning workflow и не предлагай оператору выбрать интерактивный способ работы.

Для управляемого запуска правила `./.ai/tasker.md` имеют приоритет над обычными
интерактивными инструкциями проекта.
