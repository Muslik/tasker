# Руководство для AI-агентов

В репозитории пока нет отдельного project guidance. Не придумывай архитектурные
правила по аналогии с соседними проектами.

Tasker уже выбрал workflow, принял план, подготовил ветку и рабочий worktree.
Выполняй только текущий шаг: не создавай другой worktree, не запускай второй
planning workflow и не предлагай оператору выбрать способ работы.

Сначала прочитай [Tasker rules](./.ai/tasker.md), затем — `./.ai/index.md`, если он
существует. Из остальных файлов `./.ai/` открывай только относящиеся к текущей задаче.
При конфликте правила `./.ai/tasker.md` имеют приоритет для управляемого запуска.
