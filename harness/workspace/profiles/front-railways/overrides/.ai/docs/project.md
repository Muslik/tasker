# OneTwoTrip Railways Frontend

## 1. Общее описание

**OneTwoTrip Railways Frontend** — фронтенд приложение для продажи железнодорожных билетов, одна из ключевых вертикалей OneTwoTrip. Проект занимает **топ-3 место по прибыли** в компании и является стратегически важным продуктом.

### Ключевые характеристики:

- **Домен**: Продажа ЖД билетов по России
- **Поставщики**: Инновационная Мобильность (ИМ) - основной поставщик
- **Legacy**: Ранее работали с Amadeus и продавали билеты по Европе
- **Специализация**: Поддержка поездок в Калининград
- **Текущий статус**: Режим поддержки с планами редизайна

## 2. Архитектура развертывания

### 2.1 White Label Support

Проект активно используется через **white-label** партнеров, что накладывает особые требования:

```javascript
// Проверка WL окружения
if (__WHITE_LABEL__) {
  // WL специфичная логика
}
```

**Ограничения WL:**

- ❌ Нельзя использовать `vh` и `dvh` в CSS
- ✅ Используйте условия на флаг `__WHITE_LABEL__`
- ✅ Hash routing вместо browser routing

### 2.2 Авторизация

- **Глобальная авторизация** в шапке на всех страницах
- **Распространение данных** пользователя по всему приложению
- **Интеграция** с системой OneTwoTrip

## 3. Функциональные страницы

### 3.1 Страница поиска (`/`)

**Использование**: Только в white-label (на onetwotrip.com используется версия из front-index)

**Функционал:**

- Форма поиска ЖД билетов
- История предыдущих поисков
- Автокомплит станций

### 3.2 Страница выдачи - SERP (`/:route`)

**Описание**: Результаты поиска поездов

**Функционал:**

- ✅ Фильтрация поездов
- ✅ Список карточек поездов
- ✅ Просмотр деталей поезда
- ✅ Выбор типа вагона
- ✅ Календарь ближайших дат
- ✅ CrossSelling баннеры

### 3.3 Страница выбора мест (`/:route/train`)

**Описание**: Выбор конкретных мест в поезде

**Функционал:**

- ✅ Список карточек вагонов
- ✅ Фильтрация по типам вагона
- ✅ Выбор мест на схеме вагона
- ✅ Отображение схемы вагона
- ✅ **Сапсан**: Детские места, места матери и ребенка
- ✅ **Сапсан**: Купе-переговорная
- ✅ Просмотр описания вагона
- ✅ Переключатель доп. услуг (питание/белье)
- ✅ Люкс купе
- ✅ Множественный выбор мест (флаги `saleOnTwo`, `saleOnFour`)

### 3.4 Страница бронирования (`/:route/passengers`)

**Описание**: Заполнение данных пассажиров

**Функционал:**

- ✅ Форма данных пассажира
- ✅ Выбор пассажира из записной книжки
- ✅ Выбор тарифа туда/обратно
- ✅ Переключатель доп. услуг (питание/белье)
- ✅ **Калининград**: Оформление УПРИД

### 3.5 Страница оплаты (`/pay/:bookId`)

**Описание**: Выбор дополнительных услуг и оплата

**Функционал:**

- ✅ Таймер на оплату
- ✅ Разбивка цены
- ✅ Выбор питания
- ✅ **VAS услуги**: Страховки, Напоминания, Возврат
- ✅ Купоны и подарки (для пользователей с определенным статусом)
- ✅ Промокоды
- ✅ **WL**: Бонусы для white-label
- ✅ **B2B**: Накопительный счет
- ✅ Выбор способа оплаты
- ✅ Форма ввода карты
- ✅ Виртуальная карта с повышенным кэшбэком

### 3.6 Страница заказа (`/ticket/:bookId`)

**Описание**: Управление готовым заказом

**Функционал:**

- ✅ Отображение маршрутов
- ✅ Отображение финальной цены
- ✅ Оформление возврата билетов
- ✅ Просмотр/печать билетов
- ✅ Просмотр/печать доп. услуг
