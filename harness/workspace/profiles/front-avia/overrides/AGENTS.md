# Руководство для AI-агентов

Основное руководство для всех AI-агентов находится здесь:

**[./.ai/index.md](./.ai/index.md)**

Прежде чем начать, сверься с `./.ai/index.md` и читай из `./.ai/` только те доки, что относятся к текущей задаче — не вычитывай весь каталог.

## Команды для проверки качества кода

- `pnpm lint:eslint` - запустить eslint
- `pnpm typecheck` - запустить проверку типов
- `pnpm lint:prettier` - отформатировать код
