# Авиа-вертикаль (front-avia)

Фронтенд авиа-вертикали тревел-платформы (OneTwoTrip): продажа авиабилетов и сопутствующих услуг + послепродажное обслуживание.

Пользовательский путь:
1. **Поиск** — параметры маршрута/пассажиров → список вариантов, сравнение условий и цены.
2. **Бронирование** — данные пассажиров, выбор тарифа, временное закрепление билетов.
3. **Оплата** — способ оплаты, проведение платежа, доп. услуги к перелёту.
4. **Управление заказом** — детали перелёта, статусы билетов/заявок, документы, доп. услуги после покупки.
5. **Послепродажное** — заявки на отмену/возврат, сбор документов, статус обработки, финансовые операции по возвратам.

Аудитория: частные лица, корпоративные клиенты, партнёрские (white-label) каналы — каналы не влияют на базовую логику. Продукт дорогой → приоритеты: пользователь всегда понимает статус заказа; доп. услуги — неотъемлемая часть продукта; бизнес-правила перевозчиков/платёжных систем инкапсулированы внутри.
