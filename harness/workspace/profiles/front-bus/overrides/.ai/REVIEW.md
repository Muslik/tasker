## 🎨 CSS/SCSS и стилизация

### Иерархия CSS переменных:

**Уровень 1 (Глобальные)**: `--color-*`, `--duration-*`, `--shadow-*`, `--border-radius-*` — **НЕ ИСПОЛЬЗОВАТЬ напрямую!**
**Уровень 2 (Токены)**: `--bg-*`, `--text-*`, `--brand-*`, `--error-*` — **ИСПОЛЬЗОВАТЬ**
**Уровень 3 (Компонентные)**: `--counter-default-background-color` — создавать свои для компонента

### ✅ Проверь:

- [ ] Классы именуются в camelCase (`rootIsChecked`)
- [ ] Корневой класс: `.root`
- [ ] Модификаторы: `.rootSmall`, `.rootDisabled`
- [ ] **Используются ТОЛЬКО токены уровня 2** (`--text-*`, `--bg-*`, `--brand-*`)
- [ ] Локальные переменные определены как `--local-*` (только если будут переопределяться)
- [ ] Используются готовые миксины из `@ott/ui/styles/`
- [ ] `@use` вместо `@import`
- [ ] Нет инлайн-стилей (кроме динамических)
- [ ] `data-redesigned="true"` для новых стилей при необходимости

### ❌ Антипаттерны:

- Использование deprecated scss переменных: `color: $colorBlack` вместо `color: var(--text-primary)`
- Хардкод цветов: `color: #212121` вместо `color: var(--text-primary)`
- Использование переменных уровня 1: `var(--color-blue-500)`
- Использование компонентных переменных: `var(--select-background)`
- Инлайн-стили вместо SCSS-модулей
- Глобальные стили без необходимости
- Дублирование CSS-правил
- Кастомные миксины вместо готовых из `@ott/ui`

## 📊 State Management и API

### Redux Toolkit

Для нового функционала для работы с API **всегда** используйте **RTK Query**.

### ✅ Проверь:

- [ ] Для работы с API используется **RTK Query** (не `createAsyncThunk`)
- [ ] API slice создан с помощью `createApi` в `src/slices/{module}/`
- [ ] В компонентах используются авто-сгенерированные хуки (`use...Query`, `use...Mutation`)
- [ ] Используются хуки `useAppDispatch` и `useAppSelector` из `src/redux/hooks.ts`
- [ ] Состояние обновляется иммутабельно (Redux Toolkit делает это автоматически)
- [ ] Селекторы размещены рядом с редьюсерами или в `selectors.ts`
- [ ] Для UI состояния используется `createSlice` (не RTK Query)

### ❌ Антипаттерны:

- Использование `createAsyncThunk` для простых GET/POST запросов (предпочтительнее RTK Query)
- Создание новых экшенов в старом формате
- Прямая мутация состояния Redux
- Хранение в Redux того, что может быть локальным состоянием компонента

### Пример RTK Query:

```typescript
// src/slices/myFeature/api.ts
import { createApi, fetchBaseQuery } from '@reduxjs/toolkit/query/react';

type SomeData = {
  id: string;
  data: string;
}

export const myFeatureApi = createApi({
  reducerPath: 'myFeatureApi',
  baseQuery: fetchBaseQuery({ baseUrl: '/_api/' }),
  endpoints: (builder) => ({
    getSomeData: builder.query<SomeData, string>({
      query: (someId) => `some-data/${someId}`,
    }),
  }),
});

export const { useGetSomeDataQuery } = myFeatureApi;
```

## ⚠️ Распространенные ошибки

### Смешивание логики и представления

```typescript
// ❌ Плохо
const Component = () => {
  const [data, setData] = useState([]);
  useEffect(() => {
    fetch('/api/data').then(r => r.json()).then(setData);
  }, []);
  return <div>{data.map(...)}</div>;
};

// ✅ Хорошо
const Component = () => {
  const { data, isLoading } = useGetDataQuery();

  if (isLoading) {
    return <Skeleton />;
  }

  return <div>{data.map(...)}</div>;
};
```

### Использование глобальных переменных напрямую

```scss
// ❌ Плохо
.button {
  background-color: var(--color-blue-500); // Уровень 1!
}

// ✅ Хорошо
.button {
  background-color: var(--brand-primary); // Уровень 2
}
```

### Создание SVG иконок вручную

```typescript
// ❌ Плохо
const CloseIcon = () => <svg>...</svg>;

// ✅ Хорошо
import { Icon } from '@ott/icons';
<Icon name="close" />
```

### Создание новых паттернов вместо использования существующих

- Перед созданием нового компонента проверь, нет ли похожих
- Используй существующие утилиты из lodash
- Следуй структуре существующих модулей

### Уровень важности:

- 🔴 **Критично** — должно быть исправлено перед мержем (ошибки, нарушение архитектуры, не работает код)
- 🟡 **Желательно** — рекомендуется исправить (код-стиль, оптимизация, несоответствие гайдлайнам)

```

Рекомендация: Конкретное решение с примером кода.

```
