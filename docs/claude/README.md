# tasker — проектирование harness

> **Исторический материал до решения о Temporal (2026-08-03).** Сохранён как внешний
> review и источник требований. Каноническая архитектура находится в
> [`../codex/architecture.md`](../codex/architecture.md); завершённая миграция доступна
> только в Git history и не является поддерживаемым runtime-путём.

Система, которая берёт задачу из Jira и доводит её до PR с разобранными комментами ревью, собирая под каждую задачу граф типовых шагов и исполняя его подписочными CLI-агентами.

**Статус: `pending approval`.** Кода нет — только проектные документы. Ни один исполнительный режим не запускался.

## Ревьюеру

**Самое ценное для критики** — таблица «Assumptions Exposed & Resolved» в [spec.md](spec.md). Восемь допущений, как каждое оспаривалось и чем кончилось. Рядом раздел Non-Goals: там явные отказы, включая вывод эвалов из скоупа с сознательно принятым риском.

**Про разметку источников в `research-landscape.md`.** Каждое утверждение помечено `[ОФИЦ]`, `[ВТОР]` или `[НЕ ПОДТВ]`, и разметка не декоративная. Часть находок подтвердить не удалось — например cost/time у Bernstein (документация отдавала 403) или конфликт вокруг статуса Antigravity CLI. Читая по диагонали, легко принять неподтверждённое за факт.

**Порядок чтения спеки для человека не в контексте:** Goal → Constraints → Non-Goals → Acceptance Criteria. Метаданные интервью, разбор ясности и транскрипт в конце можно пропустить — это рабочая кухня, а не содержание решения.

## Три решения, определившие форму системы

1. **Пауза при упоре в лимит подписки обязана переживать перезапуск процесса**, а рабочая директория прогона — быть обычным git worktree, в который человек может сесть и дописать руками. Вместе это означает, что движок нельзя строить как скрипт с циклом в памяти.
2. **Ожидание переводов, зелёного CI, вердикта бота-ревьюера, апрува человека и публикации версии пакета — это один примитив**, а не пять механизмов.
3. **Шаги уже существуют** в виде скиллов; отсутствует ровно движок, который умеет их связать, приостановить и посчитать. Поэтому v1 — ядро и очередь, а шаги-заглушки.
